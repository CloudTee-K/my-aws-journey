# Lessons Learned

## What Went Well

- Successfully created and configured an S3 bucket.
- Enabled static website hosting.
- Uploaded website assets while preserving folder structure.
- Verified website functionality.

## Challenges

- Initially encountered insufficient IAM permissions (`s3:CreateBucket`).
- Resolved by assigning the correct IAM permissions.

## Skills Gained

- Amazon S3
- Bucket Policies
- Static Website Hosting
- IAM Permissions
- Website Deployment

## Final Reflection

This project gave me my first hands-on experience deploying a production-style static website on AWS.

I learned how CloudFront improves performance by caching content at edge locations worldwide while securely delivering content over HTTPS.

Understanding the relationship between Amazon S3 and CloudFront was the biggest takeaway from this project.
